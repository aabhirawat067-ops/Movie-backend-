## ✨ Overview

**Movie Explorer Backend** is the server-side API for the Movie Explorer application.

It is built with **Node.js and Express.js** and works as a secure API layer between the frontend application and the **TMDB API**.

The backend keeps the TMDB API key on the server instead of exposing it directly in the frontend.

---

## 🚀 Features

* 🎬 Fetch movie information from TMDB
* 🔥 Trending movies
* ⭐ Popular movies
* 📅 Upcoming movies
* 🔎 Movie search
* 🎭 Genre-based movie filtering
* 🎥 Movie details
* 🔐 Secure API key handling through environment variables
* ⚡ REST API endpoints
* 🌐 CORS support
* 🚀 Ready for deployment with Render
